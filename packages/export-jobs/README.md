# @atlcli/export-jobs

Browser-safe, host-neutral kernel for queued DOCX and PDF exports.

This package owns versioned contracts, pure lifecycle transitions, replay and
resource policies, runtime validation, and structural host ports. It also owns
the browser-safe bounded-byte primitives, atomic host resource reservations,
restartable tombstone cleanup, and the durable finalization-intent protocol.
Export engines, durable host persistence, runners, and UI adapters live
elsewhere.
